# Исследовательский анализ рынка общественного питания Москвы

Учебный проект курса Data Science (Яндекс Практикум).  
Цель — провести исследовательский анализ рынка общепита Москвы и сформулировать рекомендации для инвесторов по открытию нового заведения.

## Содержимое репозитория

- `shut_up_and_take_my_money.ipynb` — основной ноутбук проекта:
  - загрузка и знакомство с данными;
  - предобработка (типы, пропуски, дубликаты, `is_24_7`);
  - EDA: категории, районы, сетевой фактор, посадочные места, рейтинги, корреляция, топ-15 сетей, средний чек;
  - итоговый вывод и рекомендации для инвесторов.

## Что сделано

1. **Предобработка:** приведены типы данных, обработаны пропуски, удалены явные и неявные дубликаты, создан признак `is_24_7` (круглосуточная работа).
2. **EDA:**
   - анализ категорий заведений и их распределения по районам Москвы;
   - соотношение сетевых и несетевых заведений, топ-15 сетей;
   - анализ посадочных мест, выявление выбросов и типичных значений по категориям;
   - анализ рейтингов и их связи с ценовой категорией (phi_k);
   - анализ среднего чека по районам, сравнение ЦАО и периферии.
3. **Рекомендации:** формат, локация и ценовое позиционирование для потенциальных инвесторов.
